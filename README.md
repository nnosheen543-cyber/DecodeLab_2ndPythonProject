# Expense Tracker
A simple and efficient command-line Expense Tracker built with Python. This application allows users to record expenses, calculate the total amount spent, and view a summary of their spending. The project demonstrates core Python concepts such as loops, accumulators, conditionals, exception handling, and user input validation.

## Project Description
The Expense Tracker helps users manage and monitor their expenses by continuously accepting expense entries and calculating the total expenditure in real time.
This project was developed as part of a Python Programming training program to strengthen understanding of data accumulation and mathematical operations in backend logic.

## Features
- Add multiple expenses dynamically
- Calculate total expenses automatically
- Count the number of expenses entered
- Calculate average expense
- Validate user input
- Prevent negative expense entries
- Simple and user-friendly command-line interface
